勢法について

時代劇、映画、漫画、その他の創作では武術の稽古は 専 ら試合で描かれます。
木剣で殴打したり、本身で激しく打ち合っている場合すらありますが、木剣でも殴打す
れば骨折しますし、打ち 所 が悪ければ即死します。真剣同士で強く撃ち合えばすぐに 刀
が使えなくなります。また稽古用ではなく登場人物の差料をそのまま使うなど、常識的に
考 えればありえない描写が一般的です。

上連者であれば、木剣や本身であっても寸止めを用いて安全に試合を 行 うことも可能
ですし、実際に稽古としても有用です。
し か し そ れ で は 迫 力 に 欠 け る と い う こ と で 、非 現 実 的 な 稽 古 風 景 が 多 様 さ れ て き ま し た 。
これが武術への大きな誤解を生む結果になっているのは、些 か問題であると言えます。

実際の武術の稽古の主体は、その技法と戦術を学ぶ約束稽古として流祖や代々の師家が
案出した「カタ」の修得が修業の中心であり、これをカタ稽古と呼びます。
「カタ」には「型」或いは「形」の字を当てるのが一般的ですが、天心流では「勢法」
の字を当てています。

型に嵌ってはいけないという教えから、鋳型の「型」の字を用いず、また手順を守って
形式をただなぞるのではないという教えから「形」の字も用いません。
「勢」は文字通りの 勢 い 働 きを意味し、軍勢や兵力の意味も含みます。そして「法」
は法則を意味し仏教では真理を示す文字でもあります。
心 技 体 の 働 き を 状 況 に 相 応 し く 用 い る と い う 、天 心 流 の 精 髄 を 示 し て い る 当 て 字 で す 。

勢法稽古は攻防を学ぶ上で欠かせない稽古法であり、修業の中心に位置づけられていま
す。

ただ、原則として天心流で勢法と呼ぶのは、流儀の技法の中でも格別なもののみです。
その他を呼称する際は単に技法等と 称 します。
わかりにくいので、勢法を代用する場合もありますが、立合の抜刀 術 一二本、坐法
小太刀抜刀 術 七本、組太刀七本のみが基本的には勢法となります。

それ以外はすべて技法となりますが、一般でいう 所 のカタと同様のものとお 考 え下さ
い。

仕 合 稽 古 に つい て

天心流に限らず、古来より、丸太刀を用いた仕合稽古は
行 われてきました。
江戸中期以降には、現代の剣道の原型となる防具と竹刀
が開発され、安全に試合を 行 えるようになったことから、
以降多くの流儀の稽古は試合中心に偏重し、カタ稽古が
軽視されるようになりました。

当たったか当たらないか、そして安全で恐怖心がなく、
運動量が増えることでスポーツ的、遊戯的な側面から多く
の流儀に普及し、現在に至ります。

現代もカタ稽古は無意味で、試合稽古を中心とした方が
合理的であるという 考 え方が根強くあります。
確かに形骸化したカタ稽古であれば、それは有効性を失したものとなりますが、往時の
武士が 命 のやりとりという経験を通じて 培 われてきたカタが無意味であるわけがありま
せん。
そ れ は 多 く の 場 合 、そ の 意 義 を 失 っ た 形 骸 化 し た カ タ 稽 古 の み を 学 ん だ こ と に よ る 勘 違
いであるといえます。
