武道と武術について

武道とは柔道、剣道、弓道、空手道、合気道、銃剣道などに代表される現代武術の総称
です。
これらが「道」を冠するようになったのは明治維新以降になってからで、華道や茶道、
香道などの芸道に倣ったものです。

こ れ は 講 道 館 の 設 立 者 で あ る 嘉 納 治 五 郎 先 生 が「 柔 術 」の 型 や 制 度 を 見 な お し 、
「柔道 」
と名を 改 めて創始したことに始まると言われています。
剣 術 を 剣 道 、弓 術 を 弓 道 と い う よ う に 、
「 術 」の 字 を「 道 」に 変 え る こ と で 、武 藝 に「 徳 育 」
の意味を持たせ、体育と徳育両面の効用を謳いました。
武士階級が消滅し、多くの武藝が廃れていく中で、武藝を存続させるための工夫だった
と言われています。

江戸期において「武道」は、主に「武士道」の意味で用いられていました。
そ の た め 、明 治 維 新 以 前 の 武 藝 を 武 道 と 分 け て 「 古 武 道 」と 称 さ れ ま す が 、こ れ は 用 語
の成立順を 考 えると正しくありません。
現在用いられている「武道」は、あくまでも明治維新以降に創流された振興武術を指す
新語であって、これに「古」を附すのは 誤 りであると言えます。

そのため石井先生は古武道という用語を好まず、天心流では武術、或いは武藝（武芸）
と 称 し、より明確に現代武道と区別して表現する場合は、古流武術、古流、又は古武術
と 称 しています。

中には、古武術という古称は江戸時代には存在しなかったものだから、使うべきではな
い と い う 論 も あ り ま す 。（ そ れ は 古 武 道 の 語 も 同 様 と 言 え ま す が ）
純然たる伝統の保存という観点から見れば、確かに一理ある意見です。
しかし同時に現代において、流儀の特性をどう表現し、伝えていくかというのもまた、
伝統の保存という意味で極めて重要です。

連綿と受け継がれてきたことを的確に表現出来る用語であり、差別化を図る意味で極め
て有用です。
そ う い う 意 味 で は 古 武 道 も ま た 有 用 で は あ り ま す が 、石 井 先 生 の 意 志 を 尊 重 す る 形 で 、
天心流では使用を避けています。

また２０００年代から、古武術という用語が伝統とは乖離した 形 で世間に知られるよ
うになりました。
わずかに伝統の流儀も注目されましたが、長期的な意味で伝統の保存に益するような
影響はなく、誤解が広まるのみだったと言えます。
用語の知名度がいかに高まっても、その実体が正しく伝わり、そして市民権を獲得して
伝統保存に役立つようでなければ意味がありません。
