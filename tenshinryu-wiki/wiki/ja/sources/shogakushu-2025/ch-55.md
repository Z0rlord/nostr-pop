刀剣の基礎知識

ここでは今後必要となる、基礎的な刀剣の教養を簡単に紹介します。

日本刀の所持について

よ く 誤 解 さ れ る の は 、「 日 本 刀 の 所 持 に は 免 許 が
必要」というものです。
これは猟 銃の免許と取り違えられたのか、はたま
た 日 本 刀 に 付 随 す る 「 銃 砲 刀 剣 類 登 録 証 」（ 登 録 証 ）
が免許と勘違いされたのか、或いは危険なものだから
当然免許が必要という思い込みからかもしれません。

実際は購入したり譲り受けた際に、名義変更の手続
きを 行 うだけです。
入手後二十日以内に、登録証に記載されている都道府県の教育委員会に「所有者変更
届出書」を郵送、または持参して提出します。
これは刀剣の現所有者を明確にして登録するだけなので、審査や確認等は 行 われませ

ん。
特に確認の連絡、返信等もありません。

もし家の倉などから未登録の刀剣類が 見 された場合は、所轄の警察署に問い合わせの
上 、警 察 の 指 示 に 従 っ て 下 さ い 。こ の 際 、発 見 し た 刀 剣 類 を 直 接 持 参 し た り 、刀 剣 商 に 持
ち込むなどしないように注意して下さい。登録証の無い刀剣類の携行により、銃刀法違反
に問われる危険性があります。
警 察 に 出 頭 し「 銃 砲 刀 剣 類 等 発 見 届 」を 提 出 し た 後 、警 察 署 発 行 の「 発 見 届 出 済 証 」を 受

銃 砲 刀 剣 類 登 録 審 査 会（ 月 一 回 程 度 ）で 審 査 を 受 け て 認 め ら れ る と 、登 録 証 が 発 行 さ れ 所 有
が認められます。
日 本 古 来 の 製 法 に よ っ て 鍛 錬 し 、焼 き 入 れ を 施 し た 刀 剣 の み が 認 可 さ れ 、太 平 洋 戦 争 中
などに作刀された一部の刀剣、また海外製の刀剣などは認可されません。
また美術刀剣として価値の無いもの（破損が激しい、 甚 だしい研ぎ減りで刃文が残っ
ていなかったり、火災で激しい焼身・焼身のもの等）と判断された場合にも、認可されま
せん。
認められなかった刀剣は切断処分を受けることになります。
このようにして切断された刀剣は残欠と呼ばれます。

日本刀、模造刀、武具の持ち 運びについて

日本刀（真剣）の運搬には 必 ず登録証をセットで携行する必要があります。

ま た 真 剣 で あ る か ど う か に 関 わ ら ず 、必 ず 袋 や ケ ー ス に 収 納 し す ぐ に 取 り 出 せ な い 状 態
にする必要があります。
そしてまた、これも真剣であるかどうかに関わらず、 必 ず「正当
な運搬の理由」が必要です。
こ れ は 稽 古 、演 武 、人 に 見 せ る 、譲 る 、販 売 す る 、ま た 入 手 、購 入
した帰りであるなどです。
護身などは理由になりません。

模 造 の 仕 込 刀 （ 仕 込 杖 ）な ど は 外 か ら は 武 具 と は わ か り ま せ ん が 、
そ れ を 意 図 的 に 隠 し て 所 持 す る こ と も ま た 罪（ 軽 犯 罪 法 第 １ 条 ２ 号 ）
となり、前述のすぐ取り出せない状態でもないことから、罪に問わ

仕込刀なども 必 ず収納して持ち運ぶようにして下さい。

太刀と 打刀について

太刀は一般に反りが深く、太刀拵えを用い腰に吊るす
刀剣様式を指します。
戦国時代以降には反りが比較的浅めで帯に直接指す打刀
が台頭します。

この区別を完全に 行 うのは 難 しいですが、一般には銘
を切る位置で判別します。

太刀は腰に吊るした際に佩表（自分の身体側が
佩裏、それに対して外側を向くのが佩表）に、打刀
は 帯 刀 し た 際 に 差 表（ 自 分 の 身 体 側 が 差 裏 、そ れ に 対
して外側を向くのが差表）に銘を入れます。
しかし 逆 に銘が切られている場合もあり、 拵 えで
判断する場合もあります。

注 意 し な け れ ば な ら な い の は 、太 刀 の 語 は 、 必 ず し も こ う し た 刀 剣 様 式 を 表 現 す る 場 合
にのみ使われるわけではないということです。
この太刀の呼称は刀剣全般を表現する場合にも用いられます。
つまりそれが打刀であっても太刀と表現されることが多々ありますのでご注意下さい。

白鞘について

白 鞘（ 或 い は し ら ざ や ）は 別 名 休 め 鞘 、油 鞘
とも呼ばれます。
これは朴の木で作られ、刀身の保管目的で
用いられるものです。
長期間刀身を入れておくと、刀 油や、揮発
した刀 油の成分が鞘を痛め、また刀身も錆び
やすくなります。
そのため保管時には白鞘に入れます。
そして刀身の代わりにツナギと呼ばれる、
刀 の 形 をした朴の木で作った木太刀を併せて
作り、これを 拵 えに充てがいます。
ツナギを用いない場合、刀身を 失 った 拵 え
がバラバラになってしまうためです。

任侠映画では白鞘で使用される描写がなさ

れていますが、本来はそのまま使用するものではありません。
不可能ではありませんが、鞘も柄も続飯（米糊）にて接着させ
ているだけの簡単な作りであり基本的に耐久性に乏しく、鍔もな
いため本来の用途ではありません。

真剣の購入と 使用について

模造ではない 刀 を真剣、本身などと呼称します。

特に初学者の場合、稽古用として本身を購入はおすすめしません。
十分に安全に 刀 を 扱 えるようになるまでは購入は控えた方が良いでしょう。

もちろん、模造刀であっても怪我を負うリスクはありますが、真剣と比較すると基本的
には軽微な怪我で済みます。

稽古用ではなく、観賞用としての購入の場合も、刀剣の知識を身につけたり、実際に
美術館などで鑑賞して、ご自身の好みが分かってからのほうが良いかと思います。

刀剣は通常刀剣商で購入します。現在はネットオークションなどもありますが、よほど
目利きでない場合は良い結果にはならないことが多いので注意して下さい。
また現代刀工に注文打ちを依頼するという選択肢もあります。自分好みの作刀が出来ま
す。

美術刀剣について

基本的にすべての刀剣は、法律上には美術刀剣とされます。
しかし一般的に、観賞用、美術的価値の認められた刀剣と、歴史的価値の認められた
刀 剣 、 そ し て 武 用 、 つ ま り 武 術 の 稽 古 や 演 武 、 試 斬 向 け と さ れ る 刀 剣 に 大 別 出 来 ま す 。 一*
これは価値観の問題であり、これが正しいというわけではありません。

美術的価値、歴史的価値、希少性の低いものにわけられ、武用に用いるものは後者を用い
る場合が多いと言えます。

実際には複数の価値を持つ場合も多々ある

稽 古 、演 武 、試 斬 な ど 、武 用 と し て の 刀 剣 の 扱 い と 、一 般 に 刀 剣 商 で 扱 わ れ た り 、美 術 館 、

研 ぎ について

刀剣はまず作刀時に粗研ぎ（鍛冶押し）が 施 され、その後
研師の手によって本砥がなされます。
一般に刃文に合わせて化粧研ぎが 施 されます。

研 ぎ は 単 に 切 れ る よ う に し た り 、傷 を 消 す た め だ け で な く 、
日本刀の持つ神秘性と美術性を最大に引き出すという側面が
あります。

日本刀の天敵は錆です。
汚れは錆を誘引し、人の手脂や唾、血などは即座に錆を生
みます。
そのため定期的なメンテナンスはもちろん、錆が出始めた
ら専門家である研師に研ぎ（日本刀研磨）を依頼します。

刀 には研ぎ減りという言葉があり、研ぐということは文字通り刀身を減らすというこ
とです。
つまり再生することは出来ないため、素人が研ぐと肉置などが損なわれ二度と戻せませ
ん。
肉置とは刀身の厚み、特に鎬筋から刃までの厚みを指します。
重ねとほぼ同義ですが、重ねは特に数値的観点で厚みを測るものであり、また棟重ねを
