第十世師家相伝まで

私 が入門した頃は、片手に数える程も稽古者がおらず、そのため 私 は必死で友人知人
を誘い、門人を増やすことに尽力しました。
天心先生は門人が増えることを強く願っていたので、 私 は入門直後からホームページ
制作の重要性を説明し、許可を求めましたが 頑 なに拒絶されました。
十ヶ月ほど説得に要し、どうにかホームページ制作の了 承を半ば無理やり得たのです
が、その拒絶の理由は後ほど明らかになります。
入門から一年の頃、天心先生から代範として認められ、門人も徐々に増えます。

私 が 天 心 流 に 入 門 後 一 年 か ら 二 年 ほ ど 経 っ た 頃 か と 思 い ま す が 、天 心 先 生 か ら 「 天 心 流
は国家により禁止されている」というお 話 をされました。
これがホームページ制作を許可しなかった原因でした。
しかし 私 はすぐに法的拘束力のないものだとわかり、そのことを天心先生にお伝えま
した。
念の為、三鷹警察署にも直接確認の電話を入れましたが、やはり同様の見解で、若者へ
の懲戒であろうとの回答でした。
およそ半世紀にも亘って隠れるように指導していた呪縛から、ようやく解き放たれたと
いうわけです。

また石井先生の「自分のことを 公 にするな」という遺言についても、ほぼ同時期に教
えて下さいました。しかし「それはあくまでも 公 にであって、信頼する門人にまで隠せ
というわけではないと思います」という言葉をお伝えしました。
そ れ か ら 、 徐 々 に 石 井 先 生 の 逸 話 を 話 さ れ る よ う に な り 、今 ま で 天 心 先 生 が 「 聞 い た 話
だ と 」と 枕 詞 で 言 っ て い た 内 容 の 多 く が 、石 井 先 生 の 教 え で あ っ た こ と も わ か り ま し た 。
私 に石井先生のことを明らかにする中で、流儀の由来についても詳しく話されるよう
になっていきました。

２０１１年の２月、思い詰めた様子で、天心先生からご自宅に招かれました。
そ し て 天 心 先 生 が 以 前 お 見 せ し て く れ た 、 短 歌 の 刻 ま れ た 太 刀 を 私 に 手 渡 し 、「 こ れ か
らはもう流儀を任せるから」と内証を 頂 きました。
「子も継がず、空しく枯れ逝く九代で 流名御太刀に刻み留めん」
これは流儀伝承を断念した天心先生が平成八年（１９９６年）にご友人の彫師の方にお
願いして刻んで 頂 いたものです。
こ の 時 点 で 入 門 か ら ３ 年 未 満 と あ ま り に 短 い 期 間 で の 相 伝 は 、さ す が に 早 す ぎ ま す が 、
天心先生のご年齢を 考 えて、内証を授けるというご意思でした。

しかしご存知の通り、その直後である２０１１年３月１１日に東日本大震災が起こりま
した。
これに危機感を強めた天心先生は、他流の諸先生方の強い推薦もあり、２０１２年２月
１１日の建国記念日に 私 に相伝印可を授けられます。
