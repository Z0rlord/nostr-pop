起居について

本章では天心流における起居の作法について紹介、解説をしていきます。
起居とは一般用語で立つことと座ることを意味します。

起 居 は 普 段 何 気 な く 行 っ て い る 所 作 で す が 、武 家 礼 法 と し て は 細 か い 作 法 が あ り ま す 。
これは敵意を示さず 美 しい所作としての礼法という面だけではなく、武士としての隙
を 生 じない所作であるということと、身体機能を 培 うという意味でも重要なものです。

まず原則として起居においては、床に手を突かないように注意します。
両手を開けておくことで、咄嗟に応じる心構えを 表 すだけでなく、自重をコントロー
ルすることで自ずと静かな所作となります。

また視線は対者の膝あたりを目安として定めます。視線が定まらないと落ち着きがない
ように見えてしまいます。

着座ついて

坐ることを一般に着座と言いますが、着座の際には袴捌きを 行 います。
袴 の 裾 は 踵 に 引 っ か け た り 、誤 っ て 踏 み つ け て し ま う こ と が 多 く 、転 倒 や 躓 く な ど 粗 相
の原因となるだけでなく、いざという時に後れを取る恐れがあります。
それを未然に防ぐための所作が袴捌きです。また坐した時に、 袴 を 美 しく 整 えるとい
う見た目の上でも大切です。

この袴捌きには 刀 を持っていない時と提刀の時とで異なり、またそれぞれにいくつか
の種類があります。
原則として両手が空いている場合には両手で袴捌きを 行 い、片手が塞がっている場合
は、片手にて 行 います。

正しい袴捌きは、起立や咄嗟の行動時において、粗相と不覚を防ぐ上で重要な意味があ
ります。
いずれの場合も 美 しい所作となるよう 心 がけて下さい。
また原則的に着座の際は片膝ずつ床に突けます。
略 式 と し て 両 膝 を 同 時 に 突 く 場 合 も あ り ま す が 、所 作 に 隙 が 生 じ や す く 、ま た 所 作 が 早
くなってしまうため、原則的には用いません。

また裾を払う方法の場合、初学では 美 しく 整 える意味で強く裾を払いますが、実際の
所作としてはあまり 埃 を立てないように静かに 行 うように注意して下さい。

無手にお ける 扇坐での袴捌き

無 手 一に
* おける扇坐での袴捌きには、四種に分けられます。
これらの用法には正式な名称が無いため便宜上名称を附していますが、名称を覚える
必要はありません。

一般用語で何も持たない手のこと。素手、徒手、空手とも。

一、膝裏擦り

腿から膝の裏を擦るように 袴 を捌く方法です。

お尻側から両膝の裏に両手刀を指し入れるようにして 袴 の裾を引き上げます。
この時、膝裏と 袴 の 間 に隙間を作る心持ちで 行 います。膝裏と 袴 が密着するようにす
ると、 袴 が突っ張り座りにくくなります。
またすぐに両手は両膝前に移します。そのまま膝を曲げると手を膝裏に挟めてしまいま
す。

そして左膝を真正面ではなく、心持ち左側に開くようにして床に突きます。

そして右膝はおよそ真横を向く程に開きます。

次に右膝を正面に向けながら床に突き矢倉坐になります。
この時右膝は、左膝の時と同様に、少し右側に開く程度に突きます。
両手を左右の 袴 の裾の両端を掴み、左右に開きます。

その後、両足の甲を床に突け腰を下ろして扇坐となり、 袴 の裾を処理し居住まいを正
します。

袴 を摘み上げるようにする方法です。

まず両手を自然に垂らした程度の位置で、 袴 を摘み僅かに上

武 道 用 の 袴 で す と 、概 ね 相 引 き 止 ま り（ 袴 の 脇 開 き の 下 端 部 ）
の下部辺りとなります。

そ し て 腰 を 沈 め て 、左 膝 を 真 正 面 で は な く 、心 持 ち 左 側 に 開 く よ う に し て 床 に 突 き ま す 。
右膝はおよそ真横を向く程に開きます。

次に右膝を正面に向けながら床に突き矢倉坐になります。
この時右膝は、左膝の時と同様に、少し右側に開く程度に突きます。
両手を左右の 袴 の裾の両端を掴み、左右に開きます。

その後、両足の甲を床に突け腰を下ろして扇坐となり、 袴 の裾を処理し居住まいを正

一、股割り

両手で股下から 袴 を叩くようにして裾を割る方法です。

膝を曲げてやや前屈みとなりながら、両手を股の 間 に垂らすようにして下ろします。
膝の横程まで手の平を下ろし、手首を内に曲げるようにして 袴 を払います。
同時に左膝を真正面ではなく、心持ち左側に開くようにして床に突きます。
右膝はおよそ真横を向く程に開きます。

次に右膝を正面に向けながら床に突き矢倉坐になります。
この時右膝は、左膝の時と同様に、少し右側に開く程度に突きます。
両手を左右の 袴 の裾の両端を掴み、左右に開きます。

その後、両足の甲を床に突け腰を下ろして扇坐となり、 袴 の裾を処理し居住まいを正
します。

提刀にお ける 扇坐での袴捌き

ここでは提刀、つまり右手に 刀 を持っている際に用いる袴捌きを解説します。
すべて片手で 行 いますが、あくまでも片手が塞がっていることから片手で所作を 行 っ
ているため、提刀の時のみに用い、無手、空手では決して 行 わないように注意して下さ

これは初学者向けで、片裾ずつ払います。

腰 を 屈 め つ つ 、左 掌 に て 左 手 首 を 内 側 に 折 り 曲 げ 、内 腿 を は た く よ う に し て 左 の 裾 を 払

次 に 、右 足 を や や 右 に 開 い た 後 、右 の 裾 を 左 手 に て 払 い 、右 膝 を 正 面 に 向 け な が ら 床 に 突

その後、両足の甲を床に突け腰を下ろして扇坐となります。
刀 を右に置いて、左右の手で 袴 の裾の両端を摘み、腰を僅かに浮かせつつ左右に引き

その後、 袴 の裾を処理し居住まいを正します。

起立について

一、扇坐からの起立について

起立時は着座時よりも手を突きやすく注意を要します。

起立の際には、まず 両 つま先を立てて跪坐となります。
足の甲を床に付けたまま立ち上がらないように注意して下さい。

そして信（真）の間では、間合
を詰めぬように、両足で同時に真上
に立ち上がります。
これを提灯が上下に伸び縮みす
る様子から提灯立と呼びます。

提 灯を折り畳む様子

行 の間以上の場合は、跪坐から右足を僅かに出し片膝立ちとなります。

この際、右足は出来るだけ小さく前に出すようにします。目安としては右足を出した際
に、右足の踵が 左 の膝を超えないようにして下さい。

そして静かに立ち上がり、右足を引いて左足に揃えます。

右足を小さく出すのも、最後に前足を引くのも、対者との間合を保つためです。

置刀から起立する場合は、まず 刀 を取り、 刀 を腰に付けるようにして、次に跪坐とな
ります。
その後は無手での起立と同様となります。

一、胡坐からの起立について

胡坐から起立する際も扇坐と同様に、立つ際に手を突かないように注意します。

まず前の足（上の足）をやや前に出し、重心を前に移しながら後ろ足のつま先を立て
片膝立ちとなります。

静かに真上に立ち上がります。
前の足を引いて、後ろ足に揃えます。

刀 を置いている場合は、まず 刀 を取り、 刀 を腰に付けるようにして、次に跪坐となり
ます。
その後は無手での起立と同様となります。
