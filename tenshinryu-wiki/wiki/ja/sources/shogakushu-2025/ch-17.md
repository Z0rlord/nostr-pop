武士と侍について

武士という用語と 侍 という用語の厳密な解説を 行 うのはとても 難 しいものがありま
す。
石 井 先 生 は 武 士 と い う 用 語 を 用 い 、「 侍 は 低 い 身 分 を 指 す 」 と 天 心 先 生 に 教 え て い た
そうですが、学説的には異なります。

侍 は高い身分の武士に用いられていたものであり、江戸期には武士階級全般に用いら
れた用語です。
「 さ ぶ ら う 」に 由 来 し 、こ れ は 貴 人 の 側 に 控 え る こ と を 意 味 し 、そ こ か ら 転 じ て 侍 （ 侍
る）になったと言われます。
また武士は初期には武芸という意味で用いられており、それが兵として用いられはじめ

ます。
い ず れ も 江 戸 期 に は 士 分 を 指 す 用 語 と し て 用 い ら れ て お り 、少 な く と も 二 つ の 用 語 の 間
に 身 分 の 上 下 は 存 在 し な か っ た と 考 え ら れ ま す 。 一*

しかし現在、天心流では原則的に士分を指す場合には武士の語を用いるようにしていま
す。
確かに石井先生の言葉は学説的には否定されるものかもしれませんが、私達がもっとも
大切にすべきは流儀の伝統と教えです。
なんらかの意図や歴史的文化的背景に由来する可能性もあり、私達が安易にこれを改変
するのは、ややもすれば伝統の改変に繋がる危険性があるからです。

これは技法にも通じる天心流における原則です。
自分たちの経験や 考 えと異なるから、常識と異なるから、学説と異なるからと、いち
いち伝承を曲げてしまえば、たちまちのうちに伝統は歪み、形骸化したものとなるでしょ
う。

一
* な お こ の 用 語 の 成 立 と 定 義 の 問 題 は 、身 分 階 級 と し て 武 士 の 誕 生 と 同 様 に 難 し い 歴 史 文 化 研 究 の 課 題 の 一
つとなっている。
