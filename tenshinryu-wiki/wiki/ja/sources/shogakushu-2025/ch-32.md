剣坐禅について

足は禅宗では
一般に結跏趺坐
などを用います

床面に接した低い位置にある窓

結跏趺坐

光願では日々の稽古でまずウォームアップとして基礎稽古などを 行 います。
そ の 後 、 稽 古 場 内 の 地 窓 一を
* 開けてその前に並び、或いは縁側に並び、朝日を受けなが
ら坐禅を 行 います。
日々の雑念を払い、稽古に集 中する
ための重要な儀礼でした。
また常在戦場
の心構えを持ち、
常に死を意識し
て不動心を 培 う
という意味もあ
ります。

一
*

地窓

が、天心流では胡坐を用います。
稽古の中で 行 い、身に 刀 を帯びて、ないしは両刀を置いて 行 い、 刀 と離れぬという程
の意味で剣坐禅と 称 します。
大 小 二 本 指 し で 行 う か 、大 刀 の み 脱 刀 し 陰 陽 暗（ 右 左 後 ）何 れ か に 置 く か 、ま た 大 小 共
に外し、大刀は陰陽暗（右 左 後 ）何れかに置き、小刀を両腿の下に横に差し入れて置き
ます。

ま ず 胸 前 に て 合 掌 し 、そ の 後 左 手 を 下 に 、右 手 を 上
にして両手を組みます。

帯刀時には、臍下丹田は柄下となるため、両手は柄下に置く

そ し て 両 手 は 臍 下 丹 田 一に
* つけ、拇指同士の 間 に紙一枚ほどの隙間を作り、両拇指をつ
けないように注意します。
禅宗ではこの手の 形 を法界定印と呼びます。
背 中 を 丸 め ず 真 っ 直 ぐ に し て 、顎 を 引 い て（ 頷 く よ う に 顎 を 首 に 近 づ け る の で は な く 、
頭部全体を後方に引くという意味合いです）姿勢を正します
両眼は半眼（薄目）として鼻筋を通して両拇指の隙間を見る如く視線を落とします。
実 際 に 見 る と う つ む い て し ま う の で 、あ く ま で 視 線 の み 落 と し ま す 。実 際 に は 拇 指 の 間
は見えません。

一
*

呼吸は鼻からゆっくりと 口からさらにゆっくりと吐きます。
剣坐禅の時間は明確に決まっていませんが３～４分程度を目安にします。

その後、金打を 行 い本格的な稽古を開始します。

稽古時間の都合などによって省 略する場合もありますが、現在も稽古前に剣坐禅を 行
います。
また遅れて参加する際にも、各自で３～４分、剣坐禅を 行 ってから参加するようにし
て下さい。
