置刀について

昔日の武士は屋内に入る際、原則的に大刀を腰から外しました。
そのため屋内で大刀を帯びることはなく、また室内において坐る際も同様に大刀を帯た
まま坐ることは通常ありませんでした。

多くの古流では大刀のみを帯びて正座にて技法を 行 います。江戸期の武家礼法として
は極めて 珍 しいことであり、そのことから中にはこれを揶揄して正座居合などと貶す人
もいます。
しかし稽古の中でのことであり、それぞれが伝承する大事な教えであり、相応の意義を
有するものであって、少なくとも現代に生きる我々は間違ってもそれを批判するべきでは
ありません。

ですが、流儀としての教えはアイデンティティであり、他流にとってはその流儀の伝承
が大切なのと同様に、 私 たちにとっては天心流の伝承がそれ以上に大切です。

で す か ら 天 心 流 の 稽 古 に お い て は 、大 小 を 帯 び た ま ま 扇 坐 に て 着 座 す る こ と は 絶 対 に 行
わないよう注意して下さい。
指導の際に、脇指が不足したなど、やむを得ない場合において大刀を脇指の代用として

帯 び て 扇 坐 と な る こ と は あ り ま す が 、そ う し た レ ア ケ ー ス を 除 い て は 、 必 ず 脱 刀 の 後 着 座
します。

そして着座した後に本指を置きます。
これを置刀と 称 します。別称を休太刀と呼びます。

置 刀 は 単 に 刀 を 置 い て い る の で は な く 、武 人 と し て 常 に 戦 い へ の 備 え と し て 、可 能 な 限
り身近に置いているものです。
ですから床に放置しているものではありません。
しかし実情として、往時の武士も生活の中で、置いた 刀 から離れることがありました
し、現代でも稽古の中で 刀 を床に置いておくことがあります。

だからこそ危急の際に 刀 を取り損ない不覚を取ったり、 刀 を 誤 って取り違えるなどと
いうことがないよう、 刀 の置き様にまで 心 を付けることを教えるのがこの置刀であり、
儀礼としての側面ではないことを心得て下さい。

刀 の置き方に陰陽暗の三種類があります。
以下にそれぞれの置き方と注意点を解説します。

一、陰 の 置 刀

着座の際、右側、陰に置く場合です。
これは目上への作法となります。

現 代 で は 薄 れ つ つ あ る 文 化 で す が 、往 時 は 右 利
きが原則であり、生まれつきの利き手に関わら
ず、左利きは右利きに矯正される文化でした。
このことから江戸時代の武士は左腰に帯刀し、
右手で抜刀したため、左手で抜刀を 行 うことは
基本的にはありませんでした。

そのため右側に 刀 を
置 く と い う こ と は 、咄 嗟
の時に左手で抜刀する
か 、持 ち 替 え る 必 要 に 迫
られるため、自分が 刀 を用いることなく、対者に害意が無いこ
とを示すこととなります。

柄を前に、切先を後ろに向けます。
刃は内側として、 刀 の柄頭と小尻を結んだ線が、自身と平行
となるように 刀 を置きます。

刀 に は 反 り が あ る た め 、柄 を 自 身 と 平 行 に な る よ う に 置 く と 、
必 ず小尻側が開いてしまうので注意が必要です。

刀 を取らないということを示すため、 刀 を身体から 拳 を横に
して二個から三個ほど空けます。

対者との間合が 行 の間以上の場合は、鍔が膝頭の位置に来る
ようにして 刀 を置きます。
対 者 と の 間 合 が 心 の 間 や 信（ 真 ）の 間 と い っ た 近 い 場 合 に は 、刀
の柄が対者との境界を侵すことを防ぐために、写真のように柄頭
を膝頭まで下げて置きます。

一、陽 の 置 刀

着座の際、左側、陽に置く場合です。
これは左手で 刀 を取り、右手で柄を持
ってすぐに抜刀出来ることから、同格や
目下、気が置けない（親しいの意味）間柄
への作法となります。
また緊張状態にある際に、対者への
警戒心を示す場合にも用います。

柄を前に、切先を後ろに向けます。
刃は内側として、 刀 の柄頭と小尻を結
んだ線が、自身と平行となるように 刀 を置きます。
刀 に は 反 り が あ る た め 、柄 を 自 身 と 平 行 に な る よ う に 置 く と 、
必 ず小尻側が開いてしまうので注意が必要です。

いざという時にすぐ刀を取れるように、 刀 は身体から 拳 を横
にして一個ほど空けて置きます。

対者との間合が 行 の間以上の場合は、鍔が膝頭の位置に来る
ようにして 刀 を置きます。

一、暗 の 置 刀

着座の際、後ろ側、暗に置く場合です。

対者との間合が心の間や信（真）

の間といった近い場合には、 刀 の柄

が対者との境界を侵すことを防ぐた

めに、写真のように柄頭を膝頭まで

下げて置きます。

刀 を背に置くことで、陰に置くよりも敬意を示すこととなります。 刀 を 預 けない場合
に 最 も丁寧な作法となります。
また 刀 を左右に置くと邪魔になる場合などにも用います。

通常は柄頭を陰（右）に向け、切先を陽（ 左 ）とします。

刃は自分の方に向くようにし、 刀 が背
と平行になるように置きます。
（技法によっては、稽古としてやや斜
めにして置く場合もあります）
また極 力、柄頭と小尻の中心が身体
の中心に来るように置きます。

切先の向きは、上座との位置関係によ
って変化します。
特に儀式の席や、身分差が明白な席な
どで上座が陰陽（右左）何れかにある
場 合 、そ ち ら に 切 先 を 向 け な い よ う に 刀
を置くようにします。

訪問先の玄関で、腰の物（ 刀 ）を
武家奉公人や家人に預けた場合、信頼
関係などある場合は、着座の後に背後に
置いてくれることがあります。
そうした際には、刃を外に向けて置いてくれる場合があります。また柄の向きの陰陽
（右左）がどちらになるか分かりません。
急事に不覚を取らないため、事前に 刀 の置き様をそれとなく確認しておくことが重要
です。
