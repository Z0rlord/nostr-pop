気合について

気合とは武術において広く用いられる掛け声のことで重視されます。
自 ら を 鼓 舞 し た り 、集 中 力 を 増 す 、ま た 無 意 識 の 抑 制 を 解 除 し て 火 事 場 の 馬 鹿 力 を 発 現
する等の効果があります。
敵に対しては威嚇して気勢を削ぐ、 驚 かせて隙を作る等の効果があります。
また場合によっては味方を鼓舞する、味方に所在を知らせる等の副次的な効果もありま
す。
天心流では気合を特に気当てと呼びます。

このように気合は実戦において重要な役割を持つものです。
しかし日頃の稽古で十分に気合を出してこれを練らなければ、いざという時に効果のあ
る気合を出せるものではありません。
稽古場ではつい恥ずかしがって思い切って声を出せないものですが、その恥ずかしがる
気持ちこそを恥じて、惰性ではない気合を稽古の中で 心 がけることが重要です。

天心流で気合は剣術において用います。
抜刀術では攻刀者の場合などは除き、原則的に気合を用いません。
強 く 息 を 吐 き 出 す よ う に「 ハ ッ 」と 云 う 無 声 の 気 合 を 用 い ま す が 、あ く ま で も 腹 の 内 に 含

む気合であり、積極的な発声を 伴 うものではありません。
こ れ は 抜 刀 術 と い う 性 格 上 、咄 嗟 の 防 技 で あ り 、ま た 抜 討 の 場 合
は静かに 行 うことが肝要だからです。
但し、攻刀者は用いる場合があります。

しかし剣術では積極的に烈帛の気合を用います。
打 方 は 「 ヤ ァ 」、 仕 方 は 「 ト ゥ 」 と 気 合 を 用 い ま す 。
「 ヤ ァ 」は 矢 を 意 味 し 、
「 ト ゥ 」は 楯 に 当 た る こ と を 意 味 し ま す 。
