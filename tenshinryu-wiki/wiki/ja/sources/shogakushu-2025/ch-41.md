鯉口について

鞘 の 開 口 部 の こ と を 鯉 口（ ま た は「 こ い く ち 」）と 呼
び ま す 。こ れ は 鯉 の 口 に 似 て い る こ と に 由 来 し ま す 。
別名では鞘口とも呼ばれます。

刀 を鞘に収めている時、基本的に刀身は鞘の内側
と接することなく浮いた
状態になっています。こ
れによって刀身の表面に
擦れて傷などが付かないように保護されています。
そしてその 刀 は 鎺 ・ 鈨 と鯉口部分が密着されており、これ
によって容易に刀身が鞘から抜けないようになっています。
これを「鯉口が固い」と表現します。

しかし繰り返し 刀 を抜き入れしていると、鞘の内側が削れ
て密着度が低下し、意図せずに鞘から 刀 が抜け落ちてしまう
危険性が高くなります。
これは「鯉口が緩い」と表現され、そのように 刀 が抜け落

ちることを「鞘走る」と言います。

平生に武士が帯びる 刀 を差料、或いは差前、佩刀などと呼
びますが、稽古の 刀 と異なり、鞘走ることを防ぐため、そう
した 刀 の鯉口は固くなっており、いきなり柄を持って抜刀し
ようとしても、容易には抜けなくなっています。

そのため抜刀を 行 う
には、まず予備動作と
して「鯉口を切る」と
いう段階が必要になり
ます。
これは左手で鍔を利用して一寸（およそ 鎺 の分）
ほど 刀 を押し出す動作のことです。
動作としては些細なものですが、生死を分ける
重要な所作となります。

外切り ・ あ ら わ 切 り

鎺

外切りはもっともスタンダードな方法で、基本と
なる方法となります。
別名をあらわ切りと呼びます。

外切り・あらわ切り

拇指を鍔に掛けて、鯉口を切ります。
拇指の位置は刃の直 上を避けてやや内側に置きます。
これは万が一鞘走った時に、拇指を切らないための用心です。
手 の 位 置 と 鍔 が 遠 い 程 に 、拇 指 で 鍔 を 押 す 力 が 弱 ま る の で 、基 本 的 に 左 手 の 人 差 し 指 側
が鍔に付く程の位置に置きます。

内切り ・ 隠 切 り

内 切 り は 不 意 打 ち の 際 、特 に 坐 法 、脇 指
を抜刀する際に用いられます。
文字通りに鍔の内側から拇指で鍔を押
して鯉口を切ります。
鍔で隠すように 行 うことから別名を
隠切りと呼びます。
鯉 口 を 切 る と い う 動 作 は 、抜 刀 を す る 上
で必須なため、拇指が鍔に掛かるという
ことに対して武士は極めて敏感でした。
そのため内切りは反応を僅かに遅らせ
る効果があります。
坐法では特に手元が見えやすいために、
不意打ちでは重要となります。

通 常の内切り

控切り

内切りには、拇指を使わずに 拳 を握り

拇指と人差し指で鍔を押すようにして 行 う

ものもあります。

これは通常よりさらに鯉口近く（鍔に手

が触れるほど）を握らねば出来ません。

非常に鯉口が固い場合に有効な方法で
す。

また左手を逆手にして鞘を取る際にも

小指側で 行 う場合があります。

控切りは拇指と人差し指の二指を用いて鯉口を切る方法です。
拇指は外切り、内切りと同様に用いますが、人差し指も鍔に掛けて用います。

そして一寸（およそ３㎝）程度鯉口を切った状態のまま、拇指と人差し指で鍔を控えま
す。

拳 を握り込むことで鯉口を切る内切り

指の注意

人差し指も鍔に控えるということから控切り
と呼ばれます。
また鯉口を切った後に二指にて鍔を控えてい
る状態を控え鍔と呼びます。
この控え鍔は納刀時などにも用います。

これは基本的に咄嗟の抜刀時には用いず、
対峙した際など 予 め鯉口を切っておき、いつ
でも抜刀出来る状態にしておく際に用います。
拍子で鞘走ることを防いだり、また 刀 を引
き抜かれるなどを防ぐ意味があります。

以上鯉口の切り方を三種類紹介しました。

いずれの場合も注意しなければならないのは、鯉口を切って抜刀動作に移った時には、
鯉口を切るために用いた拇指・人差し指は 必 ず折り曲げて鞘に添えなければいけないと
いうことです。
指を伸ばしたままにすると、例えば柄が敵の刃に当たったり、強風その他思わぬアクシ
デントで切先が変化した場合に、自分の指を切ってしまう危険があるからです。

石井先生は鯉口を切った指をそのままに
抜 刀 す る こ と を「 ち ー ち ー ぱ っ ぱ 」と 称 し て 固
くこれを 戒 めました。
正しい鞘引きを 行 う上でも大切な教えです
ので、初心の内から徹底的に意識して身につ
けるようにして下さい。

また鯉口に添える左手の拇指・人差し指は、
股の部分は末端から僅かに離し、両指の腹の
中程を鯉口に掛けるようにします。
これにより左手で握るのではなく、指の腹
で引っ掛けるようにして、最小限の 力 で鞘引
きを 行 うことが出来ます。

危険な癖である「ちーちーぱっぱ」

鯉口を正しく切れていれば起こりませんが、特に初学者に見られがちな間違いとして、
鞘を持つ際に、左手が鯉口から離れてしまうというものがあります。
稽古用の居合刀など、特に鯉口が緩くなりやすいため、鯉口を切ることなく抜刀出来て
しまい、こうした癖がつきやすくなります。
特に初学の内は、ただ 刀 を抜く、素早く抜刀することよりも、正しい手順と動作を学
ぶことに集 中するように注意して下さい。

鯉口のメンテナンスについて

前述の通り、武士が平生に用いた差料と、稽古などに用いる 刀 は異なります。
往時に稽古で用いる 刀 は、 拵 えなどは質素に作られていることも多く、メンテナンス
についてもそこまで神経質に 行 われていたものありませんでした。

目釘など、事故に直結する部位はこまめに注意する必要がありますが、特に激しく抜刀
を 行 う場合には、鯉口を頻繁に補修することとなります。
平生の差料のように神経質に鯉口を補修していては、稽古より時間を割くことともなり
かねません。

ですから稽古で用いる 刀 は、しばしば鯉口が緩くなっており、鞘走ることを防ぐ意味
で、提刀において鍔を控えるというしきたりが 生 じました。
これは天心流に限らず多くの古流に共通します。

同時にあまりに鯉口の状態が悪いと、稽古に差し支える
こともあります。
またあまりに放置していると、鯉口が破損する恐れもあ
ります。
ですから定期的に鯉口は補修をする必要があります。

経木

基本的な補修方法は鞘の内側に経木を貼り付
かなり摩耗した鞘
けるというものです。
経木とは薄く削った木の板のことです。この
経木は耳慣れないかもしれませんが、おにぎり
を 包 む の に 使 用 さ れ た り 、た こ 焼 き の 舟 皿 が 経 木
で作られている身近なアイテムです。
経 木 を 適 当 な サ イ ズ に 切 り 、摩 耗 し て い る 部 位
に往時は米糊、現代であれば木工用ボンド
（稽 古 用 で あ れ ば 速 乾 性 を お す す め し ま す ）を 塗
った経木を貼り付けます。
鯉口をキツくし過ぎると鞘が割れる原因になるので注意が必要です。
貼りすぎた際などは、ヤスリで削って調整して下さい。

緊急処置として 鎺 にセロファンテープを貼り付けるというものがあります。
しかしこれは鯉口の摩耗は進み、鞘をより痛めて寿命を縮めますし、 鎺 が汚れますの
で、通常は使用を避けた方が良いでしょう。
演 武 や 稽 古 時 に 安 全 の た め 緊 急 で 行 う と い う 意 味 で は こ れ も 兵 法 で す が 、出 来 る だ け 早
くテープを剥がして、経木で補修するようにしましょう。
慣れれば小さく切った経木を貼り付けるだけなので、ほとんど時間はかかりません。
以下に刀身の状態が良くても、鞘を破損すると稽古に支障をきたしますし、割れたり欠
けた鞘を補修するのは大変な手間がかかります。
