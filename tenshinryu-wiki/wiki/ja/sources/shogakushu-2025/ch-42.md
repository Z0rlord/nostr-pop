刀の持ち方について

刀 を持つ手のこととその 働

きを手の内と 称 します。

刀 と自分を繋ぐ唯一の部位

が手ですから、この手の内は
刀 を 扱 う上で大変重要なもの
となります。

手の内は左右とも「龍の口」と呼ばれる手の 形 を作
ります。

こ れ は 烏 賊 の 口 を 少 し 緩 め た よ う な 手 の 形 で 、龍 の 口

の形状に見えることに由来します。



拇指、人差し指、中指はそれぞれ触

れず、また中指、薬指、小指の三指は

階段状になります。

右 手 は 鍔 、縁 金 一に
* 人差し指が触れない程度に鍔

柄木の鍔側を覆いかぶせる金具で、鍔に接し柄巻の巻はじめと接する

から離します。

*

正しい手の平と柄の角度

手の平に対して直角に近い

持ち方にならないように注意

して下さい。
（下写真参照）

柄は手の平に対して、斜めに持つ

ようにします。

目安としては、手相の生命線に柄

を重ねるようにイメージすると良い

でしょう。

（実際の角度は上写真を参照）

誤 った手の平と柄の角度

右手の位置の目安は、鍔と右手の 間 に鶏卵を載

せられる程度です。

可能であれば注意しつつ試して下さい。

左手は柄頭を包むようにします。

初学では左手の平の上に柄頭を載せて、左手で

柄頭を包むように持つと良いでしょう。
（左写真参照）

この際、小指が柄頭
から完全に外れる
程度とします。

両手が適切に離れて
い る た め 、テ コ の 原 理
を利用して様々な
技法をより効果的に
用いることが出来ま
す。

抜刀や剣術で素早く手の内を動かしたり持ち替えを 行
う 場 合 は 、左 手 は 柄 頭 を 取 ら ず に や や 鍔 よ り を 持 ち ま す 。

太 刀 を 持 つ 際 は 、右 手 は 通 常 よ り さ ら に 鍔 と 右 手 の 距 離
を離します。
これは介者（甲冑を着用しているという意味）では互
い に 防 御 力 が 高 い た め 、必 然 的 に 間 合 が 近 く な り や す く 、
鍔迫り合いの頻度が高くなるため、敵の鍔により指を潰
されないための用心です。
