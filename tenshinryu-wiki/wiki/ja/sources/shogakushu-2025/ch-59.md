稽古中の所作 に つ い て

稽古に臨むにあたって守るべき所作・行儀作法などが多数存在します。

これらはもちろん状 況に応じて臨機応変で一概に示すことは出来ませんが、原則的な
ものを実際の稽古の流れに沿って紹介します。

中には武藝以前に、常識の範疇と呼べるものも多数ありますが、天心流における稽古場
での共通概念として記します。

遅 刻 、 欠 席 に つい て

基本的に万全の状態で稽古に臨むには、早めの到着を 心 がけます。
予 め準備可能な場合は、着替えや稽古道具の準備など 行 いましょう。
こ れ は 天 心 先 生 が 繰 り 返 し 述 べ て い ま す が 、早 く 到 着 し て 困 る こ と は あ ま り あ り ま せ ん 。
もちろん時間前に入れない場合は時間を潰す必要はありますが、遅参の場合は取り返しが
つきません。

着替えや道具の準備があるため、開始時刻に到着するのでは遅刻となってしまう場合も

あります。稽古場が開始前から使用可能な場合、開始時刻までに着替えと道具の準備を済
ませておくのが望ましいでしょう。
遅刻、欠席の際には特に事前の報告義務等はありません。

履物に つい て

稽古場では履物は揃え、また下駄箱がある場合は下駄箱に入れてください。
また他者の履物が脱ぎ散らかされているのを見かけた場合には、これを直すように 心
がけて下さい。
こ れ は 禅 宗 で は 脚 下 照 顧 と 呼 ば れ る も の で 、本 義 は 自 ら の 足 元 を 見 直 す 自 省 の 精 神 を 示
す言葉ですが、その 表 れとして履物を揃えることを大事として、よく禅寺の玄関に掲げ
らています。
稽古とは、 自 らを 省 みて 自 らを 改 める
改過自新によって上達するものです。
で す か ら 足 元 を 顧 み ら れ な い 人 は 、自 ず と 上 達
から遠ざかると言えます。

また多くの場所は公共施設です。
施設管理者、また同じく施設を利用する人や
団 体 に 対 し て 、天 心 流 が 社 会 的 常 識 を 持 っ た 集 団
であることを示す意味もあります。
そうした信頼の積み重ねが、より円滑な活動

の 礎 となります。

そして武士として、急事に即座に対応するという意味でも、履物が整頓されていること
が重要であることは言うまでもないことです。
裸足のまま出るならいざ知らず、咄嗟の際にまず脱ぎ散らかされた履物を探すところか
ら始めるのでは、とても常在戦場の精神が 培 われているとは言えません。

なお、現在では玄関で靴を脱ぐ際に、振り返って靴を脱いで上がることで、揃える手間
を省くことが多いですが、これは本来は無作法となります。
正面を向いたまま脱いで上がり、振り向いて 改 めて靴を揃えます。
な お 往 時 は 靴 を 揃 え る の は 家 人 の 役 目 で 、 主 人 や 客 人 は 行 い ま せ ん で し た 。 一*

挨拶に つい て

稽古場では 必 ず挨拶をするようにして下さい。
門人同士はもちろん、施設関係者、警備の方などにも笑顔で挨拶を 心 がけましょう。
また他の団体、利用者の方であっても、目が合った際などには挨拶するか、そうでなく
とも会釈程度は 行 うようにして下さい。
これは円滑な稽古、施設利用の継続ための最低限のコミュニケーションです。

一
も多く、沓脱石などで脱いだり、また玄関にて腰を下ろして足を洗う、拭くなどの行為
* 草 鞋 を 用 い る 場か合
もあったため、この限りではない

挨拶は相手の顔をきちんと見て元気よく 行 いましょう。
コミュニケーションの段階でノイズがあると、稽古に集 中出来なくなります。
挨拶とは、相互に悪意がないことを示す社会的機能を有します。
それが正しく 行 えないということは、非友好的な関係性を示すことになります。

人 間 で す か ら 好 き 嫌 い が 生 じ る の は 当 然 の こ と で あ り 、無 理 に 友 好 関 係 を 構 築 す る 必 要
はありませんが、同じ空間で稽古する以上、人間としての最低限のコミュニケーションを
守るように注意して下さい。

稽古場への出入りの礼について

稽 古 場 の 出 入 り の 際 に は 、必 ず 入 口 で 一 度 立 ち 止 ま り 、
礼を 行 うようにして下さい。
日本には境界を重視する風習があり、無言での出入り
は失礼とされます。

中に居る人に対しての礼儀だけでなく、不用意に出入
りしないことで護身も意味を有します。

惰性になったり、急ぎの際などには乱れた礼となりが
ちです。
頭 を下げるというだけのお辞儀が正しく出来ない人

が、難しい技法を正しく 行 えるわけがありません。

儀礼をただのお決まり事と 考 えず、特にその日最初に稽古場に入る際の礼は、これよ
り稽古に臨む 心 を映すものであると心得て、美しく静かで丁寧な礼を 心 がけるようにし
ましょう。

足音に つい て

稽古場ではすり足を 心 がけて、足音を立てずに静かに歩くように注意をして下さい。
これは単に作法というだけでなく、足捌きの基礎であり稽古の一環になります。
日常生活の中でも 心 がけましょう。

荷物の席次に つい て

荷物は正面（神棚、国旗などのある上座）を避けて、所定の位置に置きます。
一般的には荷物は師範の位置を基準として入門 順 に置きます。
しかし実際には事前に参加者は把握出来ませんし、全員揃って稽古場入りするわけでも
ありませんから、荷物の置き場所は臨機応変に決めて下さい。
入 門 順というのは一般的な決まりごととして知っておけば十分です。
各々、互いに気を使いながら、置きたいところに置いて下さい。

道具を 跨がない

日 本 は 座 敷 文 化 で あ り 、床 に 物 を 置 く 機 会 が 多 く あ り ま す 。
そのため物を跨ぎやすく、それを蹴飛ばす、踏みつける等
して怪我や物の損傷事故が生じやすくなります。
そのため、日本では古来より物を跨がないという作法が
徹底されて来ました。
そのため特に他者の物を跨ぐということは、非常に無礼な
行為であるとされ、禁忌とされてきました。

稽古場においても、床に置かれたすべての物を決して跨が
ないように徹底的に注意して下さい。

な お 喩 え 刀 ケ ー ス に 入 っ て い た と し て も 同 様 で す 。刀 そ の も の が 露 出 し て い な く と も 、
跨ぐことは禁忌であることに変わりありません。

特に 刀 はただの道具ではなく、武士の 魂 であり、如何なる理由があっても絶対に跨が
ないように注意して下さい。喩えそれが自身の 刀 であってもです。
そしてそれを互いに徹底するようにして下さい。これは相手が目上であっても関係あり
ません。
自身の道具はもちろん、他者の道具の場合はなおさら注意して下さい。
往時であれば他者の 刀 を跨げば斬り殺されても文句は言えないものでした。

絶対に 刀 を跨がないよう注意する

物の置き 方 に つい て

原則的に上座の壁面に荷物を置かないようにして下さい。
脱いだ衣類は畳み、不用なものを出したままにしないなど、公共の場であることを意識
して、乱雑に散らかさないように注意しましょう。
また財布、携帯電話などの貴重品はきっちり自己管理を 行 って下さい。人目に付くよ
うに放置するのは不用心です。

刀の置き 方 に つい て

稽古中、壁際に 刀 を置く場合、壁
に刃側を向けて置き、剣尖は上座や
正中を避け、柄側が上座や正中を向く
ように置きます。

小太刀（脇指）について

稽古中は原則として特別な指示がな
い限りは常に小太刀を帯びて 行 いま
す。
稽古の準備が出来次第小太刀を帯刀
して下さい。

扇子に つい て

往時の武士の 嗜 みとして、四季に関わらず扇子を携行していました。
そのため天心流では原則的に稽古中にも扇子を帯びます。
天心流の技法には扇子を用いるものが多く、また演武の際には扇子を用いるため、慣れ
る意味でも欠かさず身につけるようにして下さい。

壁にもたれた り 倚りかから ない事

稽古前後、稽古中に限らず稽古場内の壁に背をもたれたり、倚りかかることがないよう
に注意して下さい。

但しそういった稽古も存在するので、そういう場合は当然除外されます。
また体調不良や怪我などの場合も除外されます。

稽 古 中 の ス マ ホ 利 用 に つい て

稽古中のスマホの利用は必要最小限に留めるようにして下さい。
特に必要な連絡もある場合もありますし、稽古に関係する場合もありますから、指導陣
含めて稽古中にスマホを使用します。
しかし稽古に無関係な長時間の利用は禁止とします。

席次について

開始時刻となったら全員整列の上着座し、対坐した指導者に礼を執り、また金打を 行
います。
席次は通常上座より入門 順 となります。

稽古開始と 終了の礼について

礼は指導者に続いて 頭 を下げ、また指導者が 頭 を上げた後に 頭 を上げます。
指導者より先に 頭 を上げないように注意して下さい。
立つ際も同様に指導者より先に立たないよう注意して下さい。
このように多くの動作は上位者に続いて 行 います。

遅参し た 場合

指導者や他の門人に軽く挨拶を済ませて、稽古の準備をします。
その後、指導者にあらためて挨拶を 行 い稽古に参加します。
もし指導者が手が離せない状 況である場合は、しばし待機するか、長くなるようであ
れば稽古に加わって、落ち着いた時点で挨拶を 行 って下さい。

刀を 振っている 人の側を 通ら ない事

基 本 的 に 稽 古 中 に は 刀 を 振 っ て い る 人 と 一 定 の 距 離 を 保 っ て 、側 を 通 ら な い よ う に 注 意
して下さい。
特に背後を歩くのは非常に危険です。

また左右や正面であっても、稽古に集 中していると気づかない場合があります。
や む を 得 ず 側 を 通 る 際 は 、 必 ず ひ と 声 か け て 、さ ら に 返 事 を 確 認 し て 通 る よ う に し て 下
さい。
声を掛けても、耳に入っていないことも多々あります。

稽 古 場 が 狭 い な ど で 、や む を 得 ず 背 後 を 通 る 際 は 、お 相 手 が 完 全 に 認 識 し て 、動 き を 中 断
するまでは通らないように注意して下さい。

逆 に稽古中は、周囲に常に気を配るように意識して下さい。
稽古ですので集 中しなければなりませんが、しかし実戦においても周囲の状 況を常に
観察することも重要な心得の一つです。
そして、相互の注意があってこそ、事故を未然に防ぐことが出来ます。

使っている物が模造刀や木剣であっても、死傷リスクが有ると心得て下さい。

刀の受け 渡し に つい て

稽古中に 刀 の受け渡しを 行 う際には、相手に刃を向けないように注意して下さい。
これは抜き身ではもちろん、鞘に納めた時であっても同様です。
横にして渡す場合、相手から見て右側に柄が来るように渡します。自分は 刀 が抜きに
くく、相手に 刀 を抜きやすいように渡すのが作法となります。

これは対象が木剣や丸太刀でも原則的には同じです。

武具の扱いに つい て

武具は丁寧に 扱 い、床に放り投げるなどしないように注意して下さい。
また様々な稽古を 行 うため、武具が稽古場の各所で置き去りになってしまうこともあ
ります。
怪我や武具の損傷を防ぐために、極 力壁際に寄せるか、適時片 付 けるように注意しま
しょう。
また他者の武具であっても、一声掛けて隅に寄せるなどして下さい。

掃除、片付けについて

稽古後には全員で稽古場の始末を 行 います。
モップがけや掃除機の利用、使用した 鏡 の整理などを 行 います。
また稽古道具などの多い指導者の手伝いをお 願 いします。

禅宗では掃除はただの労務ではなく、作務と 称 し気づきを 養 う修行と位置づけられて
います。
た だ の 作 業 と せ ず 、 稽 古 場 や 指 導 者 へ の 感 謝 と し て 、率 先 し て 行 う よ う に し て 下 さ い 。
特に古参ほど人任せにしてサボりがちです。喩え指導者であろうが、古参であろうと、
年配者であろうと無関係です。
自 ら使用した場所の始末を自身でつけられない人は稽古に参加する資格はありません。

誰かがやるのを待つのではなく、率先垂範して後輩に模範を示すようにしましょう。

退 室 に つい て

退室の際は忘れ物が無いように、十分に確認を 行 って下さい。
一 般 的 な 作 法 と し て は 、目 上 の 者 の 退 室 を 待 っ て 後 に 退 室 す る と い う も の が あ り ま す が 、
片付けや着替えの都合で一同が揃って出られるわけでもないので、気にしなくて構いませ
ん。

ま た 更 衣 室 を 利 用 す る 際 は 、他 の 利 用 者 の 方 々 に 迷 惑 に な ら な い よ う に 注 意 す る と 共 に 、
第三者の出入りがあることを踏まえて、貴重品の管理に気を配り、十分に注意するように
して下さい。

帰宅に つい て

全体での稽古終 了の挨拶の後、片付けや着替えが終わった後にも、指導者や門人に声
をかけてから帰宅するようにして下さい。
これは単に礼儀作法という問題ではなく、集団として各自がきちんと帰宅したかという
安全確認の意味があります。
例えば稽古で熱 中 症など体調不良を起こしており、トイレなどで意識を 失 っているな
ど、予期せぬ事故が想定されます。
状 況確認の上でも、きちんと挨拶をするのは重要なことです。

ま た 荷 物 が 多 い た め 、歩 い て い る 時 、ま た 電 車 や バ ス な ど に 乗 降 す る 際 に 、周 囲 の 人 に 刀
のケースをぶつけないように注意し、また電車、バス等へ荷物を置き忘れることがないよ
うに十分注意して下さい。

歴史の重みが技の重み

初版の天心流兵法初学集の発刊から気づけば十二年の歳月が経ちました。
その 間 、ずっと改訂作業を 行 っていたわけではありませんが、本書の完成には尋常で
はない時間と労力を費やすこととなりました。
その期間に天心先生が思い出されたことで、改定前とは比較にならない価値ある一冊に
なったと自負しています。

それはもちろん 私 だけの 力 ではなく、多くの方々のご助力を得てのことです。
改 めまして御礼申し上げます。

武術は武術です。身体による物理的現象なのだから、その周辺知識を知っていても知ら
なくても、腕前にはさほど影響がないと 考 える人は多くいます。
それは一見すると真理のようですがそうではありません。
私 たちは意識を持つ生物であり、認識、意志が多くの運動を機能させます。
当然、意識が変われば、動きも変わります。

歴 史 と 文 化 の 積 み 重 ね 、そ の 深 み に 驚 嘆 し 、重 み を 識 る こ と で 、 私 た ち の 動 き も 技 の 働
きも、当然影響を受けて変化します。
ですから本書を読めば視えてくるものがあり、自ずと上達します。
